## 🚀 Projects Included

### 🎙️ Task 1: Voice Assistant
A Python-based voice assistant that listens to audio input from the user and performs specific automated tasks.
- **Features:** 
  - Voice recognition using microphone input.
  - Text-to-speech output using `pyttsx3`.
  - Greeting responses and real-time Date/Time queries.
  - Automated Google Web Search based on spoken queries.
  - Graceful error handling for unrecognized speech.
- **Tech Stack:** Python, `speech_recognition`, `pyttsx3`, `webbrowser`, `datetime`

---

### ⚖️ Task 2: BMI Calculator
A command-line tool that calculates Body Mass Index (BMI) based on user-provided height and weight inputs.
- **Features:**
  - Standard metric units processing (weight in kg, height in cm).
  - Accurate categorization: *Underweight*, *Normal weight*, *Overweight*, or *Obesity*.
  - Input validation for negative numbers and non-numeric entries.
- **Tech Stack:** Python

---

### 🔑 Task 3: Random Password Generator
A security-focused password generator that builds randomized strings tailored to user requirements.
- **Features:**
  - Customizable options for letters, numbers, and special symbols.
  - Adjustable password length validation.
  - Cryptographically varied outputs using Python's `random` and `string` modules.
- **Tech Stack:** Python, `random`, `string`
